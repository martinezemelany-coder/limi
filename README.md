# Limi

**A social discovery app designed to turn shared interests into real friendships and real-world connections.**

Limi is a full-stack social application I designed and developed to help users discover people with similar interests, connect with potential friends, and find or create social experiences in their area.

## Features

- Email/password and Google authentication
- Personalized user profiles
- Multi-step onboarding experience
- Interest and activity-based matching
- Location-based friend discovery
- Social feed and user-generated posts
- Hangout creation and discovery
- Direct messaging
- Notifications
- Short-form social content
- Optional profile verification
- Responsive, mobile-first interface

## Tech Stack

**Frontend**
- React
- JavaScript
- Vite
- Tailwind CSS

**Backend & Cloud**
- Firebase Authentication
- Cloud Firestore
- Firebase Storage

**Development & Deployment**
- Git & GitHub
- Vercel
- Capacitor

## Development Highlights

- Built the application independently from initial concept through functional deployment.
- Developed reusable React components and multi-page user flows for authentication, onboarding, profiles, social discovery, and content.
- Integrated Firebase Authentication for email/password and Google sign-in.
- Designed Firestore data structures for users, posts, hangouts, and other application data.
- Implemented responsive interfaces designed around a mobile-first user experience.
- Debugged authentication, database permissions, routing, state, and deployment issues throughout development.
- Used Git and GitHub for version control and iterative development.
